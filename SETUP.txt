RYZOR — ШВИДКИЙ ЗАПУСК

1. Розпакуй ZIP.
2. Завантаж УСІ файли та папки з архіву в корінь GitHub-репозиторію. Не пропусти приховану папку .github.
3. У GitHub: Settings -> Pages -> Build and deployment -> Source -> GitHub Actions.
4. Переконайся, що основна гілка називається main.
5. Зроби commit/push. Відкрий вкладку Actions і дочекайся зеленого статусу Deploy RYZOR to GitHub Pages.
6. Відкрий опублікований HTTPS URL.

ДЛЯ ЦІЄЇ ЗБІРКИ НЕ ПОТРІБНІ: GitHub Secrets, Google OAuth, Cloudflare, Worker, база даних, Node.js або Telegram-бот.
