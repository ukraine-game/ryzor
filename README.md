# RYZOR — сайт для підключення до наявного Telegram API

Цей архів містить лише файли сайту RYZOR. Новий сервер, Node.js-проєкт або окремий процес запускати не потрібно.

## Як працює Telegram

Браузер **не завантажує `random.txt` і не отримує токен**. Сайт надсилає погоджену користувачем подію на вже наявний API: `POST /api/telegram/notify`. Твій сервер сам читає токен із приватного `random.txt` і надсилає повідомлення Telegram.

Це важливо: якщо браузер отримає токен із TXT, відвідувач зможе побачити його в DevTools або мережевих запитах. Тому сайт не повинен читати секретний файл напряму.

## Підключення до твого API

- Якщо API доступний на тому самому домені за адресою `/api/telegram/notify`, нічого змінювати не потрібно.
- Якщо API на іншому домені, відкрий `api-config.js` і вкажи його HTTPS-адресу:

  ```js
  window.RYZOR_API_BASE = 'https://api.example.com';
  ```

Твій наявний API має приймати JSON такого формату:

```json
{
  "event": "login",
  "details": {}
}
```

Події надсилаються лише після окремої згоди користувача. Без згоди запитів немає. Паролі, email, ім'я та назва пристрою не передаються.

## `random.txt`

Створи цей файл на своєму сервері там, де його може читати серверна частина, але не веббраузер і не публічна папка сайту. Орієнтовний формат:

```ini
BOT_TOKEN=ТВІЙ_ТОКЕН_БОТА
CHAT_ID=ТВІЙ_TELEGRAM_CHAT_ID
```

Не додавай справжній `random.txt` до Git. Він уже вказаний у `.gitignore`. Якщо токен колись був опублікований, відклич його через BotFather та створи новий.

## GitHub Pages

Workflow публікує тільки статичні HTML/CSS/JS та зображення. `random.txt` не використовується браузером і не додається до публічного сайту. Локальні акаунти, заявки та історія звернень залишаються в браузері й не синхронізуються між пристроями.

## Важливо

Якщо твій наявний сервер наразі лише віддає файл `random.txt` браузеру, але не має API-маршруту `/api/telegram/notify`, сповіщення не запрацюють без серверної обробки. Просто сховати адресу TXT або виключити його з Git недостатньо, щоб приховати токен від браузера.
