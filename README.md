# RYZOR — локальна версія

Статичний сайт для GitHub Pages. Реєстрація, профіль, звернення та заявки на тариф зберігаються у локальному сховищі браузера. Backend, Node.js, Cloudflare, Google OAuth і Telegram-бот для роботи сайту не потрібні.

## Каталог

У каталозі є 7 карток ігор, пошук, фільтри та вікно з описом гри. Додавання гри до каталогу не означає, що її хмарний запуск уже доступний.

## Оформлення тарифу

Користувач обирає тариф, указує нікнейм і створює серійний код. Заявка зберігається локально. На фінальному екрані можна скопіювати повідомлення з назвою тарифу та серійним кодом і відкрити чат із менеджером `@st0fen` у Telegram. Користувач надсилає його вручну. Сайт не приймає файли чи квитанції, не обробляє платежі та не перевіряє їх автоматично.

## Підтримка

Звернення та локальні нотатки зберігаються у браузері користувача. Вони не синхронізуються з іншими пристроями й не надсилаються менеджеру. Для прямого зв’язку використовується посилання `https://t.me/st0fen`.

## Публікація

1. Розпакуй ZIP.
2. Завантаж усі файли й папки з архіву в корінь GitHub-репозиторію, включно з прихованою папкою `.github`.
3. У GitHub відкрий **Settings → Pages** і вибери **GitHub Actions** як Source.
4. Переконайся, що основна гілка називається `main`.
5. Зроби commit/push і дочекайся успішного workflow `Deploy RYZOR to GitHub Pages`.
6. Відкрий адресу GitHub Pages.

## Локальне зберігання

Дані доступні лише у тому самому браузері й профілі браузера. Очищення даних сайту або використання іншого пристрою може зробити їх недоступними. Локальний парольний хеш не є серверною автентифікацією й не забезпечує синхронізацію.

## Обмеження

- Telegram відкривається лише після натискання користувачем посилання.
- Серійний код є ідентифікатором локальної заявки; він не є підтвердженням платежу та не має спільної серверної бази.
- Підписка не активується автоматично.
- Реальні хмарні сесії потребують окремої ігрової інфраструктури та відеостримінгу.
- Ping у блоці серверів є орієнтовним відображенням, а не мережевим вимірюванням.


У каталозі доступно 8 ігор, зокрема Counter-Strike 2. Натискання на картку відкриває стандартне вікно: незареєстрованому користувачу пропонується реєстрація, зареєстрованому — кнопка «Запуск» (поки це заглушка до підключення хмарних ігрових сесій).
